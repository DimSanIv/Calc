# Calc — Калькулятор в стиле OS/2

## Функционал

- Сложение и вычитание больших чисел с точностью `Decimal`.
- Интерфейс в стиле OS/2 (IBM): серый фон, крупные кнопки + и -.
- Окно «Текущая сумма» и поле «Ввод», лента вычислений в отдельном окне.
- Управление лентой: «Очистить ленту», «Скрыть» (скрыть/показать окно истории).
- Кнопки: цифры 0–9, «Очистить», «←» (backspace), «+», «-», «=».
- Поддержка клавиатуры: цифры, +, -, Enter, BackSpace, Delete, C (очистка), запятая/точка для дробной части.

## Запуск

Только стандартная библиотека Python (tkinter входит в поставку Python).

```bash
cd Calc
python calc.py
```

Окно «Лента вычислений» открывается рядом с калькулятором; закрытие крестиком только скрывает его (показать снова — через кнопку в основном окне).
